# Data licence

This file covers content **produced by this project**. Third-party source corpora are
not distributed with the repository. The one derived dataset that is redistributed,
`data/packs/tujia-open-core/`, is a CC-BY-4.0 subset with attribution (see below).

## Scope

| Content | Licence | Note |
|---|---|---|
| Source code | MIT | see `LICENSE` |
| `data/inventory/` syllable table | CC BY 4.0 | compiled here; no source names or glosses |
| `data/packs/tujia-open-core/` | CC BY 4.0 | derived from Zhou (2020), attribution required |
| Other standardised data, annotations and conversion output | CC BY 4.0 | excludes third-party word lists in full |
| Field recordings | per consent form | authorised by each speaker individually; no commercial use without permission |

## Third-party corpora

Third-party source corpora are not distributed by this project. Users obtain them from
the original publisher and follow that publisher's terms. Providing a DOI or fetch
instructions grants no licence.

`data/packs/tujia-open-core/` is the exception: it is a derived core vocabulary
(1,620 entries, 346 concepts) from Zhou, Yulou (2020) *Proto-Bizic: A Study of Tujia
Historical Phonology*, licensed CC-BY-4.0. Reuse requires attribution; the citation is
in `data/packs/tujia-open-core/NOTICE.md`.
